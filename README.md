# 牙翼 · 二手牙科设备 + 维修服务平台

牙科设备**挂网展示** + **自主上架** + **维修报修**三合一。给私域客户直接用，**不需要服务器、不需要小程序审核**。

## 🚀 怎么给客户用（3 种方式，任选）

| 方式 | 怎么做 | 适合 |
| --- | --- | --- |
| **发链接** | 微信里发 `https://zhaosirhi-cell.github.io/yayi/` | 单个客户/群里 |
| **发扫码卡片** | 直接发 `demo/扫码卡片.png`（1080×1350，朋友圈/私聊都好看） | 朋友圈、名片、门店贴纸 |
| **加到手机桌面** | 客户打开后 → Safari「分享→添加到主屏幕」/ 安卓浏览器「菜单→添加到主屏幕」 | 让客户长期留存，像 App 一样点开 |

> 页面已做 PWA：加到桌面后有独立图标（牙翼）、全屏打开、断网也能看。

## 💬 客户"能用"体现在哪（不需要后端）

客户点「立即咨询」「立即报修」「我要卖机」时，页面会**生成一段格式化好的信息**（含设备编号、价格、链接、报修单号、故障描述），客户点「复制信息」→ 粘到微信发给你即可。也可以直接点「打电话」拨给客服。

- **客服电话/微信在这里改**：`tools/demo/data.js` → 搜 `CONTACT`
- 客户的报修记录会存在他自己手机上（我的订单里能看），你收到微信消息后线下派单

## 2. 当前版本（v1.2 · 牙翼 + 维修板块）

### 品牌与色调
- 品牌改为 **牙翼**，全站文案、店铺、资讯作者、Logo 字位统一
- 整体色调统一为**绿色系**（六宫格、Banner、资讯封面、状态色全部绿色家族）

### 维修板块（一等功能）
| 位置 | 说明 |
| --- | --- |
| 底部 tabBar | 首页 · 甄选 ·（转设备）· **维修** · 我的 |
| 首页 | **维修服务大卡**（设备报修 · 48 小时上门 · 立即报修）+ 快捷条「维修报修」 |
| 维修服务页 | 预约流程 01/02/03、报修地址、维修产品、联系时间、问题描述（200 字计数 + 上传图片）、立即报修 |
| 我的订单 | 订单号搜索、5 个状态 tab（全部/待接单/待上门/已完成/已取消）、订单卡、取消报修、空状态 |
| 我的页 | 维修订单入口（含待接单数量） |

报修提交后会生成订单并跳「我的订单」，状态可流转，数据存本地。

### Banner 占位图
首页和维修页各留了一块虚线占位块（标注建议尺寸 710 × 260px），后期直接换成运营图即可。

### 卖家中心（保留）
发布商品（按类目自动切换参数模板）→ 审核（演示 2 秒自动通过）→ 上架 → 出现在商城（带「我的」角标）；
我的店铺里可上架/下架/编辑/删除，数据存浏览器本地。

### 医美内容：隐藏不删除
旧数据整包保留在 `tools/demo/data.js` 的 `aesthetic` 内容域，「我的 → 内容域 → 切换」可一键切回对比。

## 3. 改内容 / 重新打包

```bash
node tools/build-demo.js    # 改完 tools/demo/ 后重新打包成 demo/index.html
node tools/serve.js         # 本地起服务预览
```

- `tools/demo/data.js` — 两个内容域的数据 + 维修配置（地址/产品/时间/服务项/状态）
- `tools/demo/app.js` — 页面与交互逻辑
- `tools/demo/style.css` / `style-pages.css` — 样式（绿色主题）
- `tools/demo/selftest.js` — 注入式交互自测（当前 27/27 通过）
