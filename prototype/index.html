再美二手光电 小程序原型 · v1

二手医美设备挂网信息平台 + 交易撮合。所有页面按小程序规范以 375 × 812（= 750rpx 屏宽）设计， 颜色 / 圆角 / 间距 / 字号全部使用统一令牌，可直接映射为 WXSS 的 rpx 数值。 下方 8 个页面为可交互 HTML 原型，逻辑与小程序「页面 + 组件」一一对应。

设计基准 750rpx 自定义导航栏（沉浸式渐变头） 自定义 tabBar（中间凸起发布） 主题色 #2B7A4B 8 个页面 + 6 个复用组件

页面画廊 左右滑动查看，点击「独立打开」可单独预览

01 首页tab搜索 + 六宫格 + 瀑布流独立打开
02 再美甄选tab质检好机 + 多条件筛选独立打开
03 设备列表二级页分类 + 排序 + 大卡片独立打开
04 设备详情二级页主图 + 参数 + 卖家 + 咨询独立打开
05 我要卖机二级页三步发布表单独立打开
06 搜索二级页历史 + 热搜 + 榜单独立打开
07 资讯tab医美周报 / 公司新闻独立打开
08 我的tab授权登录 + 交易 + 功能独立打开
